# CoCo

A Tauri code coach with manual context checkpoints, provider/model settings, optional speech, references, and persistent tabs. Run `npm install`, `npm run desktop`, or `npm run package`. Source access is read-only; keys use Windows Credential Manager. Closing hides to the tray; tray Exit quits.

Goal progress derives checkpoints from the agreed plan and saved conversation, with visual history, protected corrections and Undo.

History exports individual/all sessions and imports validated copies through native file dialogs. External inputs start disabled on import. Stored keys and temporary captures are excluded.
