# CoCo

Tauri 2, React and TypeScript desktop foundations with VS Code light/dark themes.

Run `npm install`, `npm run build`, and `npm run desktop`. Native features are integrated in subsequent logical changes. Dependency lockfiles describe the complete 0.1 runtime.

Native context and provider modules implement bounded read-only repository snapshots, manual screenshots, local/OpenAI coaching, and compatible model discovery. Tests cover payloads, redaction and model policy; desktop controls arrive with session integration.
