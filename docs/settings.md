# Settings

Settings is organized into **Appearance**, **AI model**, **Voice**, and **API key**. Use the section buttons or Left/Right/Home/End when a section tab is focused. The API key is shared by OpenAI coaching and speech and stays in Windows Credential Manager.

**Appearance → Text size** adjusts text throughout CoCo from **85% to 150%** in 5% increments, using the slider or −/+ controls. The default is 100%. Chat, code blocks, session tabs, labels, and controls scale together. The window and icon sizes remain unchanged; controls can grow or wrap to fit their text.

Changes preview immediately. **Save settings** retains the size across sessions and restarts. **Cancel**, Escape, or closing Settings restores the previously saved size. **Reset to 100%** previews the default; Save keeps that reset. Theme and size are app-wide. Appearance can be saved without choosing a model first; coaching still requires a configured model before sending a request.

Existing settings files default to 100%. The native backend rejects sizes outside 85–150%.
